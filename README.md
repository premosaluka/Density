# 🧠 Density Classification Neural Network  

## 📌 Overview  
This project explores **breast density classification** using machine learning models.  
It is based on features generated with **Libra software** from an **anonymized dataset of breast images**.  

The main notebook, **`DensityClassificationNeuralNetwork.ipynb`**, handles:  
- 📂 Loading breast density data with extracted features (Libra software was processing and generating features)  
- 🔬 Exploring feature distributions and preprocessing  
- 🧠 Training models to detect breast density class  

---

## 🎯 Goal  
The objective is to build and evaluate models for **breast density classification**, comparing:  
- **Neural Networks (NN)**  
- **Logistic Regression (baseline)**
